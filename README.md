# xAI-Project

Group project investigating a topic in Explainable AI (XAI).

## Status

No final topic has been decided yet. Topics that we are currently investigating include **Explainable AI for medical diagnosis** (e.g. training a classifier for a
condition such as heart disease or diabetes, then using techniques like
SHAP and LIME to explain its predictions, and asking whether those
explanations are faithful/consistent) as a candidate direction — see
[`research/medical-diagnosis-xai.md`](research/medical-diagnosis-xai.md).

## Structure

- [`journal/`](journal/) — dated log of meetings, decisions, and reasoning
  (one file per entry, e.g. `journal/2026-09-21.md`).
- [`research/`](research/) — investigation write-ups for candidate topics.
- [`notebooks/`](notebooks/) — exploratory/experiment notebooks.
- [`SPEC.md`](SPEC.md) — assignment specification for this journal.
